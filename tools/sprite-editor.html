tool settings

The solid center overwrites color; the soft edge blends into neighboring pixels.

Click a color region. Shift adds a region, Alt removes one pixel, and Shift+Alt intersects. Increase tolerance to include nearby shades.

Color drift mode maps the clicked source pixel to the active palette color, then applies the same RGB shift to every opaque pixel in the selection so highlights and shadows move together.

The selected tool has no adjustable settings.
